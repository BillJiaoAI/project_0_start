步骤
============================================================
llama.cpp 推理调用步骤（v2 demo，CPU + CUDA 后端）
============================================================

0. 设置 locale
   std::setlocale(LC_NUMERIC, "C");   // 防止小数点被 locale 改掉

1. 加载后端（所有可用计算后端）
   ggml_backend_load_all();
   // 内部：注册所有编译进二进制的后端（静态模式下由单例构造时 register_backend）
   // 或运行时动态 LoadLibrary 加载 ggml-cuda.dll 等（动态模式 GGML_BACKEND_DL）
   // 可用后端由 CMake -DGGML_CUDA=ON -DGGML_CPU=ON 决定

2. 加载模型（GGUF 文件）
   llama_model_params mparams = llama_model_default_params();
   mparams.n_gpu_layers = 99;          // 卸载到 GPU 的层数（99=全部）
   llama_model * model = llama_model_load_from_file(path, mparams);
   // 解析 GGUF 头（架构/层数/词表），按 n_gpu_layers 把张量分配到 CUDA/CPU
   const llama_vocab * vocab = llama_model_get_vocab(model);  // 分词器
   // 查信息：llama_vocab_n_tokens(vocab), llama_model_n_ctx_train(model)

3. 分词（text -> token id 序列）
   // 第一次：传 NULL 获取所需 token 数（返回负值表示需要 N 个）
   int n_prompt = -llama_tokenize(vocab, text, len, NULL, 0, true, true);
   // 第二次：填充 token
   llama_tokenize(vocab, text, len, tokens.data(), n_prompt, true, true);
   // 参数：add_special=true（自动加 BOS）, parse_special=true（解析特殊标记）

4. 创建推理上下文（含 KV cache）
   llama_context_params cparams = llama_context_default_params();
   cparams.n_ctx     = n_prompt + n_predict;   // 上下文窗口大小
   cparams.n_batch   = n_prompt;               // 一次 decode 最多处理的 token 数
   cparams.n_threads = 8;                      // CPU 线程数
   llama_context * ctx = llama_init_from_model(model, cparams);
   // 分配 KV cache（每层存 K/V 张量，避免自回归时重复计算）

5. 创建采样器链（logits -> token）
   llama_sampler * smpl = llama_sampler_chain_init(sparams);
   llama_sampler_chain_add(smpl, llama_sampler_init_top_k(40));   // 保留前40个
   llama_sampler_chain_add(smpl, llama_sampler_init_top_p(0.9, 1)); // 累计概率90%；保留概率高于多少的
   llama_sampler_chain_add(smpl, llama_sampler_init_temp(0.7));    // 温度，低固定，高随机，除以温度
   llama_sampler_chain_add(smpl, llama_sampler_init_dist(seed));  // 按分布采样，softmax -> 轮盘赌权重

6. 预填充（prefill）—— 一次性处理整个 prompt
   llama_batch batch = llama_batch_get_one(prompt_tokens.data(), n_prompt);
   llama_decode(ctx, batch);
   // 把所有 prompt token 的 K/V 写入 KV cache，输出最后位置的 logits

``` llama_batch_get_one伪代码
llama_batch batch;
llama_batch_init(&batch, n_prompt, 0);
for(int i=0;i<n_prompt;i++){
    batch.tokens[i] = prompt_tokens[i];
    batch.pos[i] = i;
    batch.logits[i] = (i == n_prompt‑1) ? 1 : 0; // 仅最后一位输出logits
}
```

7. 自回归解码循环（生成新 token）
   while (n_decoded < n_predict) {
       llama_token tok = llama_sampler_sample(smpl, ctx, -1); // 从 logits 采样
       if (llama_vocab_is_eog(vocab, tok)) break;            // 结束符则停
       // 反分词：token id -> 文本片段（UTF-8）
       llama_token_to_piece(vocab, tok, buf, sizeof(buf), 0, false);
       printf("%s", buf);
       // 用刚生成的 token 构造下一个 batch（单 token）
       batch = llama_batch_get_one(&tok, 1);
       llama_decode(ctx, batch);   // 结合 KV cache 计算下一位置 logits
       n_decoded++;
   }

```
输入prompt_tokens → llama_decode(prefill_batch)
        ↓
KV‑Cache写入全部prompt KV；ctx内部生成末尾logits
        ↓
【循环开始】
sampler_sample(‑1) 消费logits → new_token
        ↓
如果EOG就退出；否则打印文本
        ↓
构造单token batch(new_token) → llama_decode(batch)
        ↓
把new_token的K/V追加进KV‑Cache，生成新logits
        ↓
回到循环开头，再次sampler_sample
```

8. 性能统计 + 资源释放
   llama_perf_context_print(ctx);   // 打印 prefill/decode 速度(t/s)
   llama_sampler_free(smpl);
   llama_free(ctx);
   llama_model_free(model);

------------------------------------------------------------
关键数据结构
------------------------------------------------------------
llama_model   : 模型权重 + 词表（跨会话共享）
llama_context : 一次推理会话状态，核心是 KV cache
llama_vocab   : 分词器（tokenize / token_to_piece）
llama_batch   : 传给 decode 的输入批次（token[] / pos[] / logits[]）
llama_sampler : 采样器链（对 logits 逐级变换后采样）

------------------------------------------------------------
编译方式
------------------------------------------------------------
源码构建：build_llama.bat  (CMake + Ninja, -DGGML_CUDA=ON)
demo 编译：v2_simple_inference\build.bat
链接库：llama.lib ggml.lib ggml-cpu.lib ggml-cuda.lib ggml-base.lib
       + cudart.lib cublas.lib cublasLt.lib cuda.lib + advapi32.lib 等系统库
注意：需用 /MD（动态 CRT）与 llama.cpp 一致
